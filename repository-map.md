## Overview

This repository map explains the public GitHub ecosystem connected to **Workpilot Ltd** and the `openbranding` GitHub profile.

The purpose of the repository map is to help visitors understand what each repository represents, how the repositories relate to each other, and where to go for documentation, product notes, case studies, examples, experiments, standards, and future development direction.

Workpilot’s public GitHub presence is organized around one central idea:

> Practical AI and software systems for real business operations.

The repositories support Workpilot’s work in:

- Laravel business systems
- AI product development
- Customer portals
- Procurement platforms
- WhatsApp commerce automation
- Workflow automation
- Governed AI-assisted software delivery
- Public documentation and proof of capability

    ↓
